# screengeek02.github.io

## Testing guidance

This repository hosts a static site and does not contain an automated test
suite. When documenting the results of a change (for example in a pull request
or change log), explicitly note that tests were not run by including the
standard phrase:

```
Not run (static site; no automated test suite available)
```

Calling out the absence of automated tests helps set accurate expectations for
reviewers while clarifying that the behavior was verified manually.
